*** Changelog ***

## 2.6.0 - 2026-09-03
### Security
- Fix unauthenticated certificate PII disclosure. [#377](https://github.com/woocommerce/sensei-certificates/pull/377)

### Changed
- Migrate the View Certificate Link block to Block API version 3. [#395](https://github.com/woocommerce/sensei-certificates/pull/395)
- Keep the certificate when course or lesson progress is reset. [#379](https://github.com/woocommerce/sensei-certificates/pull/379)
- Bump `MINIMUM_PHP_VERSION` from 7.2 to 7.4 to match the plugin header. [#383](https://github.com/woocommerce/sensei-certificates/pull/383)

### Fixed
- Decode HTML entities and strip tags in certificate text fields so markup no longer renders literally in the PDF. [#390](https://github.com/woocommerce/sensei-certificates/pull/390)
- Escape certificate link URLs on output. [#393](https://github.com/woocommerce/sensei-certificates/pull/393)
- Fix missing and untranslated strings in the block editor. [#396](https://github.com/woocommerce/sensei-certificates/pull/396)
- Raise the minimum supported Sensei LMS version to 3.7.0. [#388](https://github.com/woocommerce/sensei-certificates/pull/388)
- Stop generating blank certificates for courses that have no certificate template assigned. [#389](https://github.com/woocommerce/sensei-certificates/pull/389)
- Clean up code to meet WordPress coding standards. [#375](https://github.com/woocommerce/sensei-certificates/pull/375)
- Defer View Certificate block registration to init. [#376](https://github.com/woocommerce/sensei-certificates/pull/376)
- Prevent PHP notices and a Sensei deprecation warning when viewing or rendering a certificate whose learner no longer exists. [#378](https://github.com/woocommerce/sensei-certificates/pull/378)
- Show original issue date on certificate. [#379](https://github.com/woocommerce/sensei-certificates/pull/379)

### Deprecated
- Deprecate `WooThemes_Sensei_Certificates::$_inline_js` with no replacement. [#375](https://github.com/woocommerce/sensei-certificates/pull/375)
- Deprecate the legacy data-update registration functions `sensei_certificates_updates_list` and `sensei_certificates_add_update_functions_to_whitelist`. [#382](https://github.com/woocommerce/sensei-certificates/pull/382)
- Deprecate `WooThemes_Sensei_Certificates::reset_lesson_course_certificate` and `WooThemes_Sensei_Certificates::reset_course_certificate`. [#379](https://github.com/woocommerce/sensei-certificates/pull/379)
